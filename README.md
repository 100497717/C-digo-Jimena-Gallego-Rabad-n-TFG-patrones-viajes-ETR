# C-digo-Jimena-Gallego-Rabad-n-TFG-patrones-viajes-ETR
Código utilizado para el análisis de reducción de dimensión y segmentación de patrones de viaje con microdatos de la ETR en el TFG de Jimena Gallego Rabadán 100497717.

El archivo principal contiene:
- Construcción y limpieza de la base de datos
- Análisis exploratorio
- Aplicación de FAMD
- Visualización mediante UMAP
- Clustering mediante K-means
- Análisis de sensibilidad
